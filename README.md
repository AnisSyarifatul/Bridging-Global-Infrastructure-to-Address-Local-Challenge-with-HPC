# Monitoring Kualitas Udara PM2.5

## Studi Kasus
Proyek ini membahas pemantauan kualitas udara
menggunakan data PM2.5 yang menyerupai pembacaan
sensor IoT. Program Python menganalisis data,
menghitung rata-rata, menampilkan grafik, dan
memberikan peringatan ketika nilai melewati
ambang simulasi. Proyek ini menerapkan konsep
analisis data untuk membantu memahami masalah
lingkungan lokal dan terinspirasi oleh integrasi
AIoT dengan infrastruktur komputasi HPC.

## Tujuan
- Menganalisis data kualitas udara.
- Menampilkan perubahan PM2.5 melalui grafik.
- Memberikan peringatan berdasarkan ambang simulasi.

## Teknologi
- Python
- Pandas
- Matplotlib
- GitHub

## Cara Menjalankan
1. Instal library:
   pip install pandas matplotlib
2. Jalankan:
   python main.py

## Dataset
Data PM2.5 yang digunakan merupakan data simulasi,
bukan pengukuran sensor sungguhan.

## Pengembangan
Proyek dapat dikembangkan dengan sensor IoT nyata
dan pemrosesan data berskala besar menggunakan HPC.
